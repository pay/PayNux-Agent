PayNux Agent Privacy Policy

Last updated: November 17, 2026

Privacy summary: PayNux Agent runs an AI gateway environment on your Android device. It stores application settings and gateway configuration locally, but it also makes network connections for installation, updates, and AI services. Information you send to an AI provider is handled under that provider's terms and privacy policy.

1. Introduction

PayNux Agent ("the App") is an open-source Android application maintained by PaijoAhmad under the PayNux project. It provides a native interface for managing an Ubuntu environment through PRoot and running Hermes Agent as its underlying AI gateway engine.

This policy explains what information the App stores, how network connections are used, and what happens when you configure and use external AI services.

2. Information Stored on Your Device

The App stores information locally to provide its functionality, including:

  • Application preferences: Setup status, gateway preferences, dashboard settings, and other application configuration stored through Android SharedPreferences.
  • Gateway and Node credentials: Gateway tokens and Node-related configuration stored in Android SharedPreferences.
  • Hermes configuration: AI provider settings and other configuration stored in the Ubuntu environment, including files under the Hermes configuration directory.
  • Ubuntu environment: The Ubuntu root filesystem, installed packages, Hermes Agent source code, and runtime files.
  • Logs: Gateway and terminal output displayed by the App.

SharedPreferences and files in the Ubuntu environment should not be assumed to be encrypted by the App. Protect access to your device and its application data.

3. Configuration Backups

The App provides a snapshot export and import feature. A snapshot may contain the contents of the Hermes configuration file, including API keys, access tokens, provider settings, and other sensitive configuration if present.

Depending on storage permission and Android storage availability, snapshots may be written to the Download directory as paynux-snapshot.json, or to the App's documents directory. Version migration may also create a file named hermes-snapshot-[version].json.

Snapshot files are not encrypted by the App. Anyone who obtains access to an exported snapshot may be able to read its contents. Store backup files securely and delete them when they are no longer needed. Do not share snapshots publicly.

4. Network Connections and Data Transmission

The App requires network access for installation and AI gateway functionality. Depending on the features you use, connections may include:

  • Ubuntu downloads: Ubuntu root filesystem archives are downloaded from cdimage.ubuntu.com.
  • Hermes Agent source: The setup process clones the upstream repository from github.com/nousresearch/hermes-agent.
  • Package installation: Ubuntu APT repositories and Python package sources are contacted to download required software and dependencies.
  • PayNux repository: The project's GitHub repository and release services may be accessed when you open project links or use release-related functionality.
  • Local gateway: The App communicates with its local gateway at 127.0.0.1:18789.
  • AI providers: When you use an AI provider through Hermes Agent, prompts, conversation content, configured credentials, and related request information may be transmitted to that provider to process your requests.

The destination and content of AI requests depend on the provider and configuration you choose. The App developer does not control the data handling practices of external providers.

5. Third-Party Services

PayNux Agent uses upstream software and external infrastructure to provide its functionality. These services may receive network requests from your device or the Ubuntu environment. Their own privacy policies and terms apply to information they process.

  • Ubuntu: Ubuntu Privacy Policy
  • GitHub: GitHub Privacy Statement
  • OpenAI: OpenAI Privacy Policy
  • Google: Google Privacy Policy
  • Anthropic: Anthropic Privacy Policy

These are examples of external services. The actual providers contacted depend on your Hermes Agent configuration.

6. Analytics, Advertising, and Developer Collection

The application components reviewed for this policy do not show an integration with a dedicated advertising or analytics SDK. The reviewed gateway socket check connects to the local loopback address to determine whether the gateway port is already in use.

The reviewed application code does not identify a PayNux-operated remote endpoint for receiving AI conversations. This does not establish that external services never collect connection metadata or other information. Ubuntu repositories, GitHub, package sources, and configured AI providers may process information under their respective privacy policies.

7. Android Permissions

The App requests Android permissions for the following purposes:

  • INTERNET: Download installation files and access configured external services.
  • FOREGROUND_SERVICE: Run setup and gateway services in the foreground.
  • FOREGROUND_SERVICE_SPECIAL_USE: Support declared foreground service functionality.
  • POST_NOTIFICATIONS: Display setup progress and gateway notifications.
  • WAKE_LOCK: Keep required work running while the device is awake or performing setup.
  • REQUEST_IGNORE_BATTERY_OPTIMIZATIONS: Allow the user to request exemption from battery optimization for ongoing gateway operation.
  • VIBRATE: Provide vibration feedback where used.
  • READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE: Support shared storage access on applicable older Android versions.
  • MANAGE_EXTERNAL_STORAGE: Support the terminal's shared storage integration where the user grants this special access.

Storage access is used for terminal access to shared Android files and for importing or exporting snapshots. Android may require the user to grant special access explicitly.

8. Data Security and Retention

Application preferences, credentials, and configuration are stored on the device according to the App's implementation and Android storage behavior. The App does not claim that all locally stored credentials or exported files are encrypted.

You are responsible for protecting your device, reviewing the contents of exported snapshots, securing API keys, and revoking credentials that may have been exposed.

Removing the App may not automatically delete files that you previously exported to shared storage.

9. Children's Privacy

PayNux Agent is not directed at children under the age of 13. The App is a technical tool that requires users to configure external services and credentials.
